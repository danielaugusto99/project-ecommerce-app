# 🛒 Simple Market — E-Commerce Full-Stack (React & Node.js)

Aplicação web completa de e-commerce desenvolvida com arquitetura RESTful, integrando um frontend dinâmico e moderno em **React.js** com um backend robusto em **Node.js / Express** e persistência em **MongoDB**.

---

## 🚀 Funcionalidades Principais

- **Catálogo Dinâmico em Massa:** Importação automatizada de centenas de produtos reais/ilustrativos via script de seed integrado com a *DummyJSON API*.
- **Filtros e Pesquisa em Tempo Real:** Pesquisa instantânea por nome/descrição e filtragem dinâmica por categorias com indicador de stock.
- **Design System Próprio (Light Mode Refinado):** Interface limpa em tons suaves, com efeitos de sobrelevação (*hover elevation*) nos cartões e transição de botões para destaque visual.
- **Carrinho e Interatividade:** Gestão de estados reativos no front-end para adicionar itens e calcular contadores em tempo real.
- **API RESTful com MongoDB:** Backend estruturado com Mongoose, rotas validadas, tratamento de índices e CORS ativado.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React.js, React Hooks, Axios, CSS / Design System Próprio.
- **Backend:** Node.js, Express.js, Mongoose, CORS, Dotenv, Axios.
- **Base de Dados:** MongoDB (local / compass).
- **Ferramentas:** Git, GitHub, VS Code, npm.
