# 🛒 E-Commerce Full-Stack (React + Node.js)

Aplicação web completa de e-commerce desenvolvida com arquitetura RESTful, integrando um frontend dinâmico em **React.js** e um backend em **Node.js / Express**.

## 🚀 Funcionalidades Principais
- **Catálogo de Produtos:** Listagem com suporte a navegação por categorias (ex: roupas, calçados, jeans).
- **Filtros Dinâmicos:** Filtragem em tempo real por cor, tamanho e ordenação por preço (menor/maior) ou itens mais recentes.
- **Roteamento Dinâmico:** Gerenciamento de rotas com `react-router-dom` e integração HTTP centralizada via `Axios`.
- **API RESTful:** Backend Node.js estruturado para servir produtos, categorias e lidar com requisições com CORS ativado.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** React.js, React Router, Styled Components, Axios
- **Backend:** Node.js, Express.js, Cors, Dotenv
- **Ferramentas:** Git, VS Code, npm / yarn
